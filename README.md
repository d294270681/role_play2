# RPG 文字冒险

本地运行的文字冒险游戏：Vue 网页、Node.js 后端、规则引擎与存档。文字模型的服务、API 地址、模型和参数由用户启动后在网页配置，保存到 `web/config.json`；新环境默认未配置，专用 Kimi 登录已移除。

首次使用请阅读 [环境配置指引](docs/环境配置指引.md)。安装 Node.js 22 或更高版本后，在 Windows 上运行 `安装项目依赖.bat`，再运行 `启动游戏.bat`，浏览器打开 `http://127.0.0.1:8000/`。完整工程若已带项目内 Node、Web 依赖和前端构建，可直接启动。

网页设置支持 DeepSeek 官方 API、OpenCode Go 订阅 API、Anthropic Messages 兼容 API、通用 OpenAI 兼容服务与本地演示模式。可刷新全部模型、搜索选择，并按模型能力配置思考等级、预算、输出长度和采样参数。配置未完成时自动打开设置；连接测试后仍需点击「保存配置」，下一次行动生效。协议与分层见 [模型接入架构](docs/模型接入架构.md)。

本地图片生成功能默认关闭。用户在网页选择后，先检测硬件，达标再安装工程内的 Python、ComfyUI 和权重；生成图片时才启动模型。详细流程与目录说明见 [本地图片生成说明](ai/README.md)。

前端采用冒险工作台：左侧切换九个功能页，主区域可视化展示角色、地图、背包、进度、关系、线索与事件；战斗准备页汇总当前能力与资源，战斗回合待后续接入。界面操作与组件职责见 [前端界面与战斗扩展](docs/前端界面与战斗扩展.md)。

物品、人物关系、线索和进度由游戏过程解锁与结算，玩家通过行动调查、交谈或使用物品；页面不提供自由添加或修改世界状态的工具。角色成长需要消耗已获得的经验。旧服务更新后须重新运行 `启动游戏.bat`，再刷新网页，才能加载新的后端限制。
