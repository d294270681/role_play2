你要为这个项目创建一个新的 RPG 本。参数（本名或一句话构想）：`$ARGUMENTS`

## 1. 先读规范
- `modules/README.md`：本的目录结构、`module.md` 格式、解耦纪律。
- `core/rules.md`：引擎规则。本里所有数值（难度、伤害、危险度、关系值、进度钟）都必须能用它结算。
- `core/event-deck.md`、`core/item-dex.md`、`core/world-map.md`、`core/character-template.md`、`core/save-state.md`：各文件的模板。
- 列出 `modules/` 下已有的本，新本的目录名不能和它们重复。

## 2. 收集构想
参数里没说清楚的，用一次提问问齐，不要一条一条追问：
- 题材与基调（例：民国侦探、废土求生、仙侠门派）
- 分级：全年龄 / 青少年 / 成人
- 玩家角色：用预设角色，还是开局按 core §1.4 自建
- 规模：小（1 个地区、3–4 个地点）/ 中（2 个地区、6–8 个地点）
- 是否需要题材专属机制（如魔法、理智值、门派武学）

用户说"你看着办"时，自己定一个合理的方案，并在最后的汇报里写明。

## 3. 生成文件
目录名用小写英文或拼音加连字符（例：`wasteland-radio`），写在 `modules/<本名>/` 下：

1. `module.md`：frontmatter 填 `name`、`title`、`engine: core`、`tone`、`rating`；写简介、文件清单、规则覆盖、开局。
2. `setting.md`：世界观、势力（每个势力写一句目标和一个威胁进度钟）、主线谜团或目标、题材专属机制。专属机制要写成"对 core 某一节的替换或追加"，判定仍用 2d6 + 属性 + 技能。
3. `world-map.md`：按 core 地点模板写。至少一个危险度 0 的据点；每个地点至少 2 个可用行动，其中至少一个不需要战斗；附路线表。
4. `event-deck.md`：本专属事件至少 12 张（d66 六类，每类 2 张），用 core 事件模板；没写到的格子注明回退到 `core/event-deck.md`。
5. `item-dex.md`：只写本特有的道具（6–10 件），普通装备回退到 core。
6. `characters/`：玩家角色卡 1 张（选择自建时写一张示例卡）；重要 NPC 3–5 张完整卡，每人都要有动机、秘密、翻脸条件；敌人用简卡。
7. `saves/save-state.md`：第 1 天 · 晨的初始存档，写好开局进度钟和初始关系值。

## 4. 自检
写完后逐条检查，不通过就改：
- 所有文件名都在 `module.md` 的文件清单里，清单里的文件都存在。
- 建卡点数正确：属性各从 1 起，共分配 8 点、建卡单项上限 4；技能 6 点、单项上限 2。生命、精力、防御值、携带格、决心按 core §1.3 算对。
- 事件和地点里的判定都写了属性或技能和难度，难度只用 7 / 9 / 11 / 13 / 15。
- 存档里的进度钟在 setting 或事件里有对应的"满时后果"。
- 内容符合 `rating`；所有人物均为成年人，不写涉及未成年人的性内容。
- 没有修改 `core/` 和其他本的文件。

## 5. 汇报
列出生成的文件，用几句话概括世界观和开局。最后告诉用户用 `/skill:rpg-load <本名>` 开始游戏。
