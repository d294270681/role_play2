## 0. 使用说明与解锁纪律

本书是**模块化课程库**，不是只能从第 1 阶一路跑到第 7 阶的固定剧本。主控可以自由选择、拆分、交叉和重组玩法；每次组合都必须满足身体、关系、场所和信息暴露的前置逻辑。

1. **允许跳阶，不允许跳前提。** 可以直接选用后期模块，也可以把不同阶段的模块拼成一堂新课；但必须先补齐该模块所依赖的条件。例如：没有敏感基础，不直接安排高强度耐受课；没有稳定的控制关系，不直接写全面接管；没有乳孔开发过程，不直接写乳穴成果。
2. **每个模块有四类依赖**：生理前提、心理前提、关系前提、场所 / 道具前提。缺少任一项时，先用铺垫、试课、预告或替代玩法补足，不能硬接结果。
3. **搭配遵循“基础 → 加码 → 锁定 → 展示”的局部顺序。** 一场可以跨越多个阶段，但必须让读者看见基础建立、强度增加、规则固定和后果落地；不要求全线同步推进。
4. **同一部位优先遵循：敏感化 → 依赖化 → 条件反射 → 社会化。** 不同部位可以并行，例如外阴线推进时同步铺垫乳房线，但两条线各自的前提不能互相替代。
5. **名分通常晚于身体和规则。** 可以提前埋下称呼、暗示或试探，但正式赐名、立法、接管和公开必须有对应事件支撑。
6. **每次组合都要标注三项内容**：当前已满足的前提、这次新增的变化、下一步因此获得的可能性。这样可以自由搭配，又不会失去因果链。
7. **良性炎症原则贯穿全课**：红肿、疹、脓疱、肉芽、水泡、外翻都是敏感度工具，不是坏死。全程无剧痛，只有爽、痒、淫疼。
8. **恶毒即快感**：下限每击穿一次，快感叠加一层。心理疏导必须把羞耻翻译成「身体在吃」。
9. **排雷**：禁止子宫颈 / 宫腔的生理性描写；最深处用软肉、幽谷极尽头、嫩肉包裹处。
10. **声线铁律**：稚宁嗓音永不沙哑，永远清甜软糯。
11. **异种线说明**：前期生理锁执行人是流浪汉老臭（第 2 阶，不用动物）；第 11 阶起解锁「兽园异种线」（虫棒犬、巨蝇双棒）为后期可选模块，主控决定启用与否。两线并存，互不冲突。

### 0.2 常用搭配方式

- **同线递进**：同一部位连续加深，适合建立敏感、依赖和条件反射。
- **双线并行**：一条身体线推进，另一条关系线观察或埋伏，适合制造反差。
- **交叉触发**：用一条线的条件反射触发另一条线，例如声音、道具或称呼成为跨部位开关。
- **社会放大**：先在私密场所验证，再把同一规则带到学校、暗网或熟人环境。
- **回收验收**：一堂高强度课后安排记录、复盘、丈夫观察或日常测试，把变化固定成连续性事实。

## 1. 世界观与最高铁律

### 1.1 梦境框
全部事件是梦中模拟，纯属虚构。

### 1.2 陆渊宗旨
- 唯一目的：让她更淫秽、更敏感
- 感受：爽 / 痒 / 淫疼，禁止剧痛与惨叫
- 病变 = 良性炎症 = 改造工具
- 每次重课搭配温柔心理疏导

### 1.3 颜色恢复机制（内部改造不可逆）
充血摩擦造成的红紫可经特殊处理一夜褪去、恢复粉嫩——**仅仅是颜色**。外翻肥大、疣状凸起、肉芽满布洗不掉。「粉嫩」是给下一顿大餐准备的更干净的盘子。

### 1.4 人类禁入（第 2 阶完成后启用）
蜜穴只认：老臭的鸡巴、羊眼圈、陆渊的指套。禁止任何人类（含亦舟、后期含陆渊本人徒手）用裸手 / 嘴 / 鸡巴直接碰触——除非课表明文开例外（如陆渊徒手洗净置丸）。

### 1.5 排位铁序（随阶段更新）
- 第 6 阶：陆渊（主人）> 王主任（夫君 / 接管者）> 老臭（情夫）> 亦舟（献妻的奴才）
- 第 8 阶起：陆渊 > 王主任 > **冉入珠**（新情夫，取代老臭）> 亦舟
- 第 9 阶起：冉入珠之后插入「贺先生 / 小冯（周末天命双脚）」
- 第 11 阶起：再插入「阚守拙（描红门 · 外聘唇匠）」；宁宁名分叠加为五重——陆渊的娇淫妻奴（底）/ 王主任的夜香淫妻（根，腰窝「王奴」）/ 俱乐部 NO.001（周末公职）/ 冉入珠的宁宁（情夫）/ 亦舟的老婆（名分，终身不许碰）

## 4. 课程阶梯（按层递进）

### 第 1 阶 · 开苞与神经铺底
**目标**：把普通新婚妻做成可喷、可指奸、可命名的坯子。  
**场所**：婚房。执行：陆渊。亦舟在场或隔屏。

#### 4.1.1 羊眼圈初调
- 十四层羊眼圈（中指九透明、无名指五深紫）
- 蹲式后入指奸，逼出生平首次喷水（可连喷）
- 直播给丈夫，留下「我想看你被操」的同谋句

#### 4.1.2 无套操逼与价目表
- 颗粒螺旋肉根：正常位 → 后入 → 公狗式
- 丈夫隔屏亲口判「技不如人」
- 她主动讨环：舌舐凶茎换进阶版，舐后庭换变态版——身体挂牌

#### 4.1.3 剃白虎与三环妖骨
- 陆渊亲手剃尽耻毛
- 三环虫毛：穹窿珠毛、G 点螺旋、阴唇刷簇
- 无套中出；射精瞬间她咬他的手指、看丈夫的眼睛喊「老公」
- 赐名预备：「娇妻归亦舟，淫身归主人」

#### 4.1.4 七环污秽刑毛套
- 蟑螂触须 / 蜱虫倒钩 / 蛞蝓勺齿 / 蜈蚣步足 / 潮虫叠鳞 / 蚯蚓刚毛 / 苍蝇唇瓣
- 顺逆双指在 G 点画太极
- 她自道母狗 / 性奴 / 淫妻；主人可在此阶第一次说「我爱你」
- 赐名落地：**娇淫妻奴**

#### 4.1.5 洗手池六客轮指
- 六名调教师轮指，她扛住不喷
- 陆渊改令「不能在我手上喷」→ 禁令本身把她逼喷
- 教训：她输给的不是手指，是规矩

#### 4.1.6 洗脚盆七客十四趾（永久敏感化）
- 七人十四只大脚趾轮流插入
- 脚汗、茧屑、泥灰封存体内
- **永久：任何人脚趾插入即喷**

#### 4.1.7 封穴发酵与灵虫除秽
- 胶带封死发酵（约三昼夜）
- 拆封后黏膜吞尽秽物、更娇艳
- 七环除秽，她自行报数（数百下不错）
- 二十只医用白虫入穴啃食，敏感度 ×6
- 浓缩液回刷褶皱
- 她自拟「妻妾」，主人降为「妻奴」

### 第 2 阶 · 双锁育种（生理锁）
**目标**：稚宁蜜穴 ↔ 老臭鸡巴 双向依赖。同室即自发交合。  
**替换说明**：原犬交线整体换流浪汉。糙舌、倒钩锁死、人菌、包皮垢口粮。

#### 4.2.1 三层毒
1. **糙舌换菌**：拆封不除秽，老臭糙舌舔净后射精灌菌，体表人菌占优。此后人类手舌被黏膜判为异物
2. **倒钩锁玉**：蜱虫倒钩环戴鸡巴根，射精膨胀卡死阴道口 20–25 分钟。「被锁死」与「终极高潮」焊在一起
3. **垢粮为医**：蜱虫 + 蛞蝓双环趁腺孔最饿时重写 G 点记忆。断粮则奇痒十倍；解法 = 带垢之根戴羊眼圈插入（喂食 + 开锁，缺一不可）

#### 4.2.2 五大新规矩（锁死后当场立法）
1. 人类禁入（见 1.4）
2. 丈夫只剩看、听、抱
3. 痒了只许求；私解一次停喂一周
4. 每周六上午婚床投喂（校五日皆倒计时）
5. 她每晚向丈夫汇报痒的进度；他每周投喂后写观察记录存档  
预告三大后续：全套榨乳、肛门夹乳、穿环入珠挂铃

#### 4.2.3 阴肛轮换收官（可选加码）
- 肛门封条内发酵七日的夜香黄膏刮出喂入蜜穴，五轮，她主动翻卷吞咽
- 越界惩罚：老臭灌尿入穴、羊角搅拌；丈夫亲口接秽舔净
- 十倍高潮阈值 + 三液同喷（水 / 奶 / 腺液）
- 三大后遗症判词：腌入味、换了锁（只认粗糙肮脏）、闹饥荒

#### 4.2.4 洗脚盆接种红色毛癣菌
- 封穴约十二小时后撕封，老臭脚趾长驱
- 遇趾即喷冲刷；趾缝红色真菌嵌入尿酸微创口
- 可加「温柔剧毒」：命丈夫洗净双手，把真菌浓缩液像新婚之夜一样轻涂满褶皱——她对「爱」不设防，肉壁自己开门迎鸩

#### 4.2.5 封穴养菌 72 小时 → 开封回接
- 培养囊胀如鸭蛋；银针刺破，浆液喷上老臭包皮垢（蜜穴亲口给鸡巴接种）
- 阴唇红肿外翻、体积可膨胀一倍；空气拂过即痉挛
- 双屏对照：三十天前初调视频 vs 此刻同角度
- 十四层羊眼圈复刻第一天姿势；十倍敏感连喷
- 刑毛双环打桩完成回接
- 此后每天下午两点定时交合一小时

#### 4.2.6 七日变异三件套（老臭侧）
| 日序 | 鸡巴 |
|------|------|
| 约第 3 日 | 冠状沟红疹，拔出十分钟即痒 |
| 约第 5 日 | 疹渗黄液，抽出灰白菌丝细毛 |
| 约第 7 日 | 菌毛覆满冠状沟；系带根部两侧黄绿脓疱（黄豆起，后期可至鹌鹑蛋） |

双向：他离穴十分钟奇痒；她空巢半刻饥饿性泌蜜。

#### 4.2.7 脓疱灌穹 · 闭环
- 菌丝蹭唇染淡灰（盖印）
- 真菌毛当刷刮 G 点与最深处软肉
- 双疱压薄，最后一击同爆，浓缩原浆灌入穹窿暗兜
- 三液同喷，双锁完成

#### 4.2.8 菌群反噬四阶（超过七天不换菌液）
1. **甜味发酵失控**：蜜汁气味浓烈十倍，甜里渗旱厕骚；讲台上也会沿腿淌
2. **空巢奇痒与污秽渴求**：穴口如喘气的嘴吐白带气泡；干净物被排斥，只认带垢带毛的根
3. **洁癖隔离与拒精**：干净鸡巴 / 自慰棒引发过敏反胃，高压痉挛吐出
4. **喜秽癖觉醒与发情公厕化**：失禁潮吹；幻想吞食臭汉排泄、舔陈年脚泥；会跪求丈夫上街找任何一个脏流浪汉来填

#### 4.2.9 良性发炎与气味融合（本阶起终身背景）
- 红色毛癣菌形成共生壁垒：外来粪菌 / 尿碱菌被分解为养料，只留表面红肿充血
- 校园夜香在外缘留下洗不掉的淡「厕所感」
- **嗅觉陷阱**：初闻酯类甜香如香水；久闻则宿便 + 脚气酸臭剥出。洗不净，随体温与快感从毛孔蒸腾。知情者多闻两秒即知是腌透的便器在求欢

### 第 3 阶 · 外阴刻蚀 · 发情铃 · 暗网点火
**目标**：外阴成为展示件；上身装铃；社会暴露网点火。

#### 4.3.1 银坠刻蚀
- 十五克锯齿银质外唇重坠夹左右咬卷边外拉
- 骨质磨毛签无润滑锉卷边外侧 → 连环潮吹
- **永久装束**：银坠日常佩戴；长裤尽毁，只许膝上三寸短裙；底裤只许开裆或露底 T 裤
- 行则银坠拍腿，坐则肥唇压椅

#### 4.3.2 乳头穿环 · 发情铃
- 乳尖贯穿，各挂钛钢铃铛
- 神经交叉反射：铃晃 → 乳尖刺痛 → 下方肉壁痉挛泌汁
- 走到哪响到哪、漏到哪

#### 4.3.3 讲台活虫
- 丈夫按令将活蟑螂塞入常年敞开的蜜穴
- 板书扭腰则触须捣深处 + 银坠砸腿 + 铃响
- 课代表可闻「过期香水」——实为发酵骚汁

#### 4.3.4 暗网与诗号（本阶必须启动）
- 账号：「讲台上的夜香小精厕」
- 每场重课高清上传，面部薄码、声音微调

#### 4.10.4 轮回管（双瓮循环器具）

教具分**死物**（粪心戒 / 吮乳杯 / 八苦轮——人设计、精准伺候）与**活物**（虫 / 蛆 / 犬——不可控、各自为政）。瘾的核心 = 失控感："哪条钻到哪条褶、什么时候缩回去，她说了不算，调教者说了也不算。"定性：**粪心戒 = 根、入珠 = 瘾、虫棒 = 野**。宁宁乳穴"两穴通用、归兽园登记"，NO.001 牌添刻。

#### 4.11.4 巨蝇双棒（基因突变异种 · 活体）

## 10. 推荐推进节奏与自由编排

下面是几条**推荐路线**，用于提供节奏参考，不是强制顺序。主控可以从任一路线抽取一个模块，再和其他路线的模块组合；只要补足前置条件，路线之间可以交叉、并行或暂时停在任意节点。

| 路线 | 适合目标 | 可选模块链 | 关键前提 |
|------|----------|----------|----------|
| 外阴敏感线 | 先建立身体反射 | 初调 → 三环 / 七环 → 封穴 → 洗手池或洗脚盆 | 先有基础敏感与可承受度 |
| 老臭生理锁 | 建立固定性伴侣依赖 | 换菌 → 倒钩锁 → 垢粮 → 变异三件套 → 双锁闭环 | 先完成老臭接触与菌群铺垫 |

| 唇豆强化线 | 让局部形成习惯与记性 | 水渠 → 吊罚 → 八苦轮 → 粪心戒 → 反省室 → 大讲台 | 先建立逼唇敏感、收放口令和场所控制 |

### 10.1 自由搭配的判断规则

1. **先定主线，再选辅线。** 主线决定本回合的主要变化；辅线只负责加深感官、关系或曝光，不要让一回合同时完成多条线的终点。
2. **先做准备，再做结果。** 可以把「弹乳 + 丈夫记录」「水车 + 王主任立规矩」「暗网试拍 + 诗号试写」放在同一回合，但不能把「乳穴接客」和尚未建立的乳孔开发直接并列成既成结果。
3. **道具可以跨线，功能不能乱跳。** 同一声音、称呼、记录本或场所可以成为交叉触发器；但它在新线路中的效果必须通过一次试用或解释建立。
4. **强度可以跳，状态不能跳。** 可以把高强度玩法提前作为一次试课或风险测试，但不能因此自动获得后期永久体质、名分、条件反射或社会身份。
5. **组合后必须有收束。** 每回合至少落下一项可追踪结果：身体变化、规则变化、关系变化、公开信息或下一课前提；其余内容保留为计划。
6. **允许暂停、回撤和换线。** 某条线卡住时，可以转去推进另一条线；已形成的状态不会无故消失，除非剧情明确安排回滚、解除或替代。

### 10.2 示例编排

- **私密试探课**：亦舟心理试探 + 陆渊观察 + 温稚宁普通日常反应；结果只增加信息，不直接改变身体状态。
- **双线铺垫课**：乳头穿环准备 + 暗网试拍；前者建立身体变化，后者建立曝光风险，两条线都停在可继续节点。
- **交叉推进课**：王主任教研室规则 + 逼唇水车低档 + 亦舟记录；先立规矩，再低强度验证，最后留下记录和下一次加码条件。
- **高强度收束课**：已完成的乳房开发 + 签课 + 远程看货；主课推进身体线，签课固定自我执行，远程观看只改变亦舟获得的信息。

第 0 天仍停在表前。之后从哪条线、哪一个模块开始，由主控指定；未满足前提时，系统先写铺垫或试课，不直接跳到成果态。

## 11. 角色扮演执行协议

### 11.1 角色分配

- 主控扮演沈亦舟（亦舟）；系统只扮演当回合被指定的 NPC。
- 未被指定的角色不替主控做决定，也不替其他角色主动说完整台词。
- 角色发言保持第一人称，动作自然融入叙述，不用旁白标签解释「正在扮演谁」。
- 温稚宁第 0 天只表现为端庄、软糯、重视日常生活的普通教师；后期性格与语言变化必须有对应解锁节点。

### 11.2 每回合开始前

1. 读取 `story-summary.md`，确认日期、地点、上一幕停点和当前阶段。
2. 读取涉及角色卡，确认关系、称呼、身体状态和已执行项目。
3. 从本书选择一项当前阶段允许的玩法；未勾选条目只能作为计划、诱因或预告，不能写成已经发生。
4. 预先确定本回合的升级拍点、情绪弧线和结尾动作，避免跨越生理或剧情前提。

### 11.3 场景结构

默认按「蓄力 → 发展 → 顶点 → 余韵」推进。每个场景安排 5–8 个具体拍点，至少包含一项不可逆的决定、关系变化或档案记录；若只是试探、日常或对话场景，则不可逆拍点可以替换为新的观察信息。

场景中持续维护四条线：

- **空间线**：明确人物站位、距离、视线和道具位置；显著动作后更新空间关系。
- **感官线**：用具体的气味、光线、材质、温度和环境声落地场景；避免只写抽象的「很香」「很臭」。
- **权力线**：记录谁提出规则、谁执行、谁旁观、谁保留拒绝或谈判空间。
- **心理线**：沿「否认 → 承认 → 诱惑 → 屈服 → 整合」推进，不能把终点心理状态提前塞给第 0 天。

### 11.4 连续性与回写

- 新增道具、称呼、身体变化、关系名分、公开记录或禁令，必须在场景结束后同步写入 `story-summary.md` 与对应角色卡。
- 只有实际发生的内容才可勾选课程进度；方案库、陆渊的预案和王主任课表中的「预定」内容保持未执行标记。
- 回写使用「日期 + 地点 + 事件 + 结果 + 下一步」五项格式，避免只留下情绪而丢失状态。
- 若用户要求重写，只改动指定段落；若用户要求回滚，将受影响角色、关系、道具和条件反射一起回滚，不能只改摘要标题。
- 当前基线固定为第 0 天。任何新会话先以当前项目文件为准，不读取父目录的后期状态覆盖本项目。

### 11.5 输出形态

- 叙事消息开头写 `[地点, 日期时间]`，日期时间与时间轴一致。
- 动作和对白自然分段；不使用 Markdown 表格代替角色对话。
- NPC 应保留独立动机，可以隐瞒、试探、拖延或临时改变计划，不是只会顺着主控说话的应声虫。
- 场景末尾保持开放的行动动量，不以元评论或问题收尾；需要分支时，给出 3–4 个具体且差异明确的后续方向。

### 11.6 露骨度与边界校准

- 默认优先写关系、权力、心理和感官张力；露骨度由主控当回合明确指定，并受当前阶段连续性约束。
- 所有角色均按成年人处理；涉及现实人物、未成年人或现实伤害时，不转写为可执行的现实方案。
- 医疗、感染和身体改造条目均是梦境中的虚构设定，不应被表述为现实医学建议；若场景需要医学感，应使用虚构术语并保持叙事用途。
- 任何含糊的「跳到后期」指令，先保持第 0 天状态，等待主控指定具体阶段或解锁节点。
