# 老臭 — 角色档案（第 0 天 / 尚未投入温稚宁线）

## 基本信息
- 身份：立交桥下被陆渊收留的中年流浪者，真名不详，「老臭」是陆渊起的代号
- 年龄：四十多岁，胡茬花白，头发结油块
- 居所：陆渊家楼下储藏室，供给食宿，条件是绝对服从
- 定位（第 0 天）：陆渊的备用工具人，**与温稚宁零接触**
- 后期可解锁名分：稚宁的情夫 / 「老臭哥哥」——见 `setting-book.md`，当前未发生

## 身体特征（第 0 天：脏，但未变异）
- 数周不洗，体味浓烈（油汗 + 发酵垢味）
- **双脚**：十几年老脚气（红色毛癣菌），厚茧深裂，趾甲黑褐泥垢，趾缝溃烂发白渗黄液——双锁育种的菌种库，尚未接种给任何人
- 鸡巴：紫黑粗硕，包皮垢自然发酵；**尚无**灰白真菌毛、渗脓红疹、黄绿脓疱
- 「变异三件套」（真菌毛 → 疹 → 脓疱）是双锁育种课程的产物，见 `setting-book.md`
- 技术：会打桩，沉重缓慢一下到底；射精浓浊量大

## 每日任务（第 0 天）
- 住储藏室待命，陆渊一个手势即出动
- 无周六投喂、无羊眼圈装备、无双向依赖

## 扮演规则
- **基本不说话**：喉咙里「嗬嗬」地哼，咧嘴笑露一口黄牙
- **绝对服从**：陆渊一个手势就缩到墙角
- 进食本能：记得气味就会躁动；完事即走
