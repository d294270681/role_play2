# 夜香 RPG · 游戏主规则

> 文字跑团式调教冒险。主控 = 玩家（亦舟视角或上帝视角），系统 = GM（主持人 + 所有 NPC）。
> 配套文件：设定库 `setting-book.md`｜地图 `world-map.md`｜事件 `event-deck.md`｜道具 `item-dex.md`｜存档 `save-state.md`
> 核心体验：主控决定大方向，骰子决定意外——每天都有可能撞见计划外的事。

---

## 1. 属性面板

### 1.1 宁宁

| 属性 | 范围 | 说明 |
|------|------|------|
| 淫度 | 0-100 | ≥30 走神微痒；≥60 腿软漏蜜；≥80 每时段附加瘾发判定；100 当众失控决堤 |
| 体力 | 0-100 | <20 强制休息；强行继续则昏厥（触发"昏后货自走"类事件） |
| 暴露度 | 0-100 | 暗网热度 + 熟人怀疑度；≥60 同事开始议论；≥80 熟人撞破判定翻倍 |

**部位开发度（各 0-10 级）**：
蜜穴 / 逼唇 / 淫豆 / 乳头 / 乳穴 / 后庭 / 喉咙 / 脚心
- 每级解锁对应玩法强度（见 setting-book 各阶前提）
- 满 10 级 = 该部位"毕业"，获得永久特质（如逼唇 10 级 = 四预言全齐）

**三条瘾线（各 0-10）**：

| 瘾线 | 对应玩法 | 断粮反应 |
|------|----------|----------|
| 根（夜香 / 粪心戒系） | 王主任夜香课 | 连续 3 天未喂：淫度每日 +15，触发"闹饥荒" |
| 瘾（入珠 / 指奸系） | 冉入珠情夫课 | 连续 3 天未见：深夜欲求不满事件自动触发 |
| 野（活物 / 异种系） | 兽园 / 巨蝇 / 虫棒 | 连续 7 天未喂：听到虫鸣水声即腿软，主动寻找活物 |

### 1.2 亦舟

| 属性 | 范围 | 说明 |
|------|------|------|
| 酸楚 | 0-100 | 绿帽刺激累积；≥80 触发"哭晕 / 彻夜难眠" |
| 兴奋 | 0-100 | ≥80 触发"当场射出 / 失禁" |
| 诗兴 | 0-100 | ≥80 **强制当场作诗**（无论场合） |
| 权限等级 | 1-5 | ①完整丈夫 ②三权（看听抱）③诗号史官 ④献妻奴才 ⑤摄影署名（一个管身一个管名） |

## 2. 时间系统

### 2.1 一天六时段
`清晨(6-8)` → `上午(8-12)` → `午休(12-14)` → `下午(14-18)` → `傍晚(18-21)` → `深夜(21-次日6)`

- 每个时段主控宣告一次行动（去某地 / 见某人 / 自由指令 / 跳过）
- 深夜时段主要用于：欲求不满、封杯过夜、偷刷、突击夜访

### 2.2 日历
| 日子 | 固定倾向 |
|------|----------|
| 工作日 | 学校线（王主任）；宁宁住校期则亦舟独居触发听书 / 七秒电话 |
| 周二 | 教学评估日（黑金淫狱棒 / 描红契上门日） |
| 周五 | 描红契第二次上门；大考 / 交付日 |
| 周六 | 俱乐部日（NO.001 公职）/ 老节目：婚床投喂 |
| 周日 | 俱乐部日 / 家庭日（情夫家访高发） |

## 3. 回合流程（每个时段跑一次）

```
① 主控宣告行动
② GM 掷 d20【触发判定】
   1-3   → 意外事件：从 event-deck 抽取（地点事件表优先）
   4-10  → 平静推进：日常描写 + 微小状态变化
   11-17 → 按计划进行：主控意图正常展开
   18-20 → 加码：NPC 主动加戏 / 意外收获 / 计划外升级
③ 附加判定：淫度≥80 时掷 d20【瘾发判定】≤10 触发瘾发事件
④ 场景演绎（按 setting-book 11.3 场景结构）
⑤ 结算：属性变化 → 回写 save-state.md
```

### 3.1 掷骰方式
GM 用 Bash 掷**真随机骰**并当场展示：
```
🎲 触发判定 d20 = 14 → 按计划进行
🎲 瘾发判定 d20 = 7  → 触发！抽取瘾发事件…
🎲 事件抽取 d100 = 63 → 事件 C-13
```

### 3.2 修正值（GM 可宣告）
- 剧情戏剧性需要：±2
- 特殊日期（周二 / 周六）：对应线触发率 +3
- 道具携带：对应事件 +2（如带着粪心戒出门）
- 连续平淡：连续 2 个时段"平静推进"后，下一时段 +4（世界不会一直安静）

## 4. 检定（动作成败）

| 难度 | 目标值 | 例子 |
|------|--------|------|
| 简单 | d20 ≥ 8 | 憋住一股蜜不滴出声（淫度<50 时） |
| 普通 | d20 ≥ 12 | 公开课上零泄漏；忍痛课含声 |
| 困难 | d20 ≥ 16 | 淫度≥80 时保持淑女；排空训练九波不断 |
| 地狱 | d20 ≥ 19 | 十倍敏感 + 淫毒糕下维持人形 |

- 相关部位开发度每 2 级 +1 修正
- 失败 ≠ 惩罚，失败 = 更精彩的剧情（失禁 / 破功 / 被逮个正着）
- 大成功（20）/ 大失败（1）：GM 安排戏剧性反转

---

## 5. 事件抽取规则

1. **地点优先**：先看 world-map 当前地点的事件表（d20 映射）
2. **通用补抽**：地点表不适用时，从 event-deck 按类别掷 d100
3. **瘾发专用**：瘾发判定触发时，从 event-deck【C 类 · 瘾发系】抽取
4. **时间限定**：清晨事件池含"七秒电话"；深夜事件池含"欲求不满 / 偷刷 / 夜访"
5. **连锁**：某些事件标注 `→连锁`，结算后自动接下一个事件

## 6. 成长与结算

### 6.1 部位经验
每次调教场景结束：主修部位 +1~3 经验（视强度），满 10 点升 1 级。升级时掷 d20，≥18 额外获得"变异特质"（条件反射图谱新增一条）。

### 6.2 瘾线喂养
- 对应玩法一次：该瘾线 +1（满 10 封顶）
- 断粮按 1.1 表格触发反应
- 三线全满 = 解锁"三瘾齐发"特殊事件（顶级大考级场景）

### 6.3 亦舟成长
- 酸楚 / 兴奋 / 诗兴随场景起伏，GM 宣告增减
- 诗兴≥80 强制作诗：诗写入 poems-collection.md，暗网发布则暴露度 +5~15
- 权限等级变动必须有剧情事件支撑（见 setting-book 第 10 章规则）

### 6.4 存档纪律
- 每回合结束 GM 更新 `save-state.md`（日期、时段、属性、在场 NPC、悬置钩子）
- 新增道具 / 名分 / 条件反射同步回写对应图鉴文件
- 未解锁内容不得写成既成事实（同 setting-book 第 0 章纪律）

## 7. 快速开局

对 GM 说：
- 「**新游戏**」→ 从 save-state 第 0 天开局，掷清晨触发判定
- 「**载入**」→ 读取 save-state 当前存档继续
- 「**跳过日常**」→ 直接掷到下一个事件为止
- 「**自由行动：……**」→ 主控自定义，GM 照常掷触发判定
- 「**掷个随机事件**」→ 不等时段，直接抽事件演绎
