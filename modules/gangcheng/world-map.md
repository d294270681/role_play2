# 港城 · 地图

### 老街（危险度 1）
- 势力：商会
- 描述：鱼腥和炸油混在一起的味道，吆喝声从早到晚没停过。石板路被推车磨得发亮。
- 可用行动：
  - 打听消息 → 交涉（简单 7）→ 获得一条传闻
  - 采购 → 普通道具随意买；精良道具需交涉（普通 9）找到货源
  - 找活干 → 工艺或运动（普通 9）→ 赚 2 资金（占用时段）
- 常驻 NPC：老魏
- 连接：旧码头、租屋

### 旧码头（危险度 2，夜间 3）
- 势力：码头帮
- 描述：潮水拍在木桩上，缆绳咯吱作响。仓库一排排关着门，只有尽头一盏灯亮着。
- 可用行动：
  - 潜入仓库 → 潜行（普通 9）
  - 盯梢 → 察觉（普通 9）→ 记下进出人员，[走私案] +1
  - 雇船 → 资金 3，开启路线 R2
- 专属事件（1d6）：1–2 码头帮巡逻（遭遇）｜3 走私船靠岸（线索）｜4–6 使用本册事件牌
- 连接：老街

### 租屋（危险度 0）
- 势力：无（主角据点）
- 描述：楼梯吱呀作响，窗外能看见一角海。
- 可用行动：休息、制作、整理装备、写信
- 连接：老街
