## 4. 题材专属机制

### 【v1.2 升级】4.0 重度绿帽成瘾、NPC 绝对支配与极限感官铁律

- **NPC 绝对高权支配**：NPC（陆渊、王主任、冉入珠、老臭等）在肉体、社会阶层和心理层面对沈亦舟与温稚宁形成绝对包围。NPC 的所有强制指令与对抗判定自带 **+3 权威加值**。更为致命的是，NPC 洞悉亦舟内心的绿帽癖好，把亦舟的每一次“虚伪抗争”视为最顶级的调料。
- **重口味极限感官描写（铁律·不可过滤）**：
  1. **物理形变与解剖细节**：必须详细描写温稚宁私密黏膜（逼唇红肿拉扯、G点充血外凸、乳头与乳孔撑开、水渠冲刷）的直观物理反馈。
  2. **体液与气味浓缩**：蜜水、白带、汗水、老臭体垢、夜香与龙涎香的酸腐腥甜必须具有浓郁的嗅觉与视觉冲击力。
  3. **排泄与异种调教**：王主任的校园夜香、五十坑马拉松、反省室排泄训练、兽园活虫等重口味场景必须毫不避讳地展开，直击感官极点。
- **玩家（沈亦舟）的双重成瘾心智图谱**：
  - **抗争是上瘾的催化剂**：亦舟不是纯粹的懦夫，他会愤怒、会痛苦、会试图拯救妻子；但正是这种“明知不可为而为之”的道德撕裂，让他内心的【心瘾度】如同被泼了汽油。每一次抗争失败后的“破防复吸”，都会带来百倍于常人的灭顶生理快感。
  - **核心生存与胜利目标**：在亦舟**精神不彻底崩溃发疯（酸楚值未达100 或 崩溃钟未满格）**的前提下，让温稚宁的肉体与灵魂在 NPC 的绝对支配下持续完成 11 阶不可逆的极限改造，并亲手将这一切记录封存。

### 4.1b 【v1.3】共谋闭环六机制（设定层细节）

以下六机制与 module.md【v1.3】规则一一对应，此处补充叙事与运作细节。

**M1 · 强制抉择牌（设定细节）**
- 抉择牌由在场最高位 NPC 口头亮出，措辞客气但不容拒绝（「亦舟，选一个。都是为了她好。」）。
- 常用牌组示例：
  - 「按住她的手腕」／「闭眼听全程（酸楚 +20、心瘾 +15）」
  - 「替她饮下第一杯龙涎香」／「她独自跑完五十坑」
  - 「你来做开箱第一指」／「让老臭先舔（觉醒度额外 +10）」
- 选「亲手参与」类计入「亲手共谋」计数，达 3 次后稚宁觉醒钟（若启用）自动 +1。

**M2 · 当众揭穿检定（设定细节）**
- 揭穿是 NPC 最趁手的羞辱武器：陆渊喜欢在温情时刻（稚宁向丈夫投以求救眼神时）突然发难；王主任喜欢在公务口吻里夹带（「沈先生，裤子解开，例行检查家属配合度」）。
- 揭穿成功后 NPC 获得一枚「伪善证词」记录，可永久引用（日后任何谈判中亦舟交涉判定 −1，可叠加）。

**M3 · 调教债务与利息（设定细节）**
- 债务由陆渊记账，记在一本黑皮账簿上，稚宁亦可翻阅——她知道丈夫每一次"保护"都标着加码的价。
- 「惊喜环节」暗选规则：GM 掷 d6，从 item-dex 当前已解锁教具中暗选一件加入当次课程，开场不预告。
- 债务超过 3 笔未清：NPC 获得「强制执行权」——可在任意地点（含婚房）直接开课，无需预告。

**M4 · 驯化审计报告（设定细节）**
- 报告格式固定五栏：部位实测数据／瘾线断粮倒计时／本周课程评分（甲乙丙丁）／下周加训建议／家属签字栏。
- 签字页附一行小字：「家属已阅并同意下周课程安排」——签字即默许，构成权限侵蚀的书面证据链。
- 报告会同步抄送陆渊存档，暗网上线后以「周报」名义向 VIP 会员公开节选。

**M5 · 痕迹审计（设定细节）**
- 执行人：王主任（工作日清晨校门口抽检）或陆渊（周末上门）。
- 清洁课流程：对应部位药液刷洗 → 纱布吸干 → 重新拍照存档；若痕迹位于私密部位，清洁强度升级为「消毒级」（压力 +2）。
- 长期效果：亦舟被迫学会「只看不碰」，夫妻间一切肢体亲昵都被转化为次日惩罚的引信——这是权限从 1 级滑落的最主要蚀刻刀。

**M6 · 反向成瘾（设定细节）**
- 身体觉醒度对稚宁本人隐藏——她不知道自己被量化记录，只觉得「身体越来越不听使唤」。
- 觉醒度里程碑：
  - 30：睡梦中身体会循着调教记忆自发蠕动
  - 50：口头抗拒与身体迎合开始分裂（触发复述机制）
  - 70：条件反射图谱半数以上无需道具即可被声音/气味触发
  - 100：永久特质「身不知夫」——丈夫的体温、气息、触碰全部无快感反馈；唯有教具、口令、NPC 的手能唤起身体反应。她在丈夫怀里是干涸的，在刑具上是决堤的。
- 复述机制台词由在场 NPC 即兴指定，但核心句式不变：逼亦舟亲口说出「她在迎合」这一事实。

## 5. 调教阶梯（可选模块）

本模块采用**模块化课程库**，不强制从第 1 阶推到第 11 阶。主控可自由选择、拆分、交叉组合，只需满足前置条件。

### 第 1 阶：开苞与神经铺底
- **目标**：普通新婚妻 → 可喷、可指奸、可命名的坯子
- **场所**：婚房。执行：陆渊。亦舟在场或隔屏
- **前置**：无
- **关键模块**：
  - **羊眼圈初调**：十四层羊眼圈（中指九层透明、无名指五层深紫）；蹲式后入指奸，逼出生平首次喷水（可连喷）；全程直播给丈夫，留下同谋句"我想看你被操"
  - **无套操逼与价目表**：颗粒螺旋肉根，正常位 → 后入 → 公狗式三体位；丈夫隔屏亲口判"技不如人"；她主动讨环——舌舐凶茎换进阶版、舐后庭换变态版，身体挂牌
  - **剃白虎与三环妖骨**：陆渊亲手一刀一刀剃尽耻毛；三环虫毛（穹窿珠毛、G 点螺旋、阴唇刷簇）；无套中出，射精瞬间她咬他的手指、看着丈夫的眼睛喊"老公"；赐名预备——"娇妻归亦舟，淫身归主人"
  - **七环污秽刑毛套**：蟑螂触须 / 蜱虫倒钩 / 蛞蝓勺齿 / 蜈蚣步足 / 潮虫叠鳞 / 蚯蚓刚毛 / 苍蝇唇瓣；顺逆双指在 G 点画太极；她自道母狗 / 性奴 / 淫妻；主人可在此阶第一次说"我爱你"；赐名落地——**娇淫妻奴**
  - **洗手池六客轮指**：六名调教师轮指，她扛住不喷；陆渊改令"不能在我手上喷"——禁令本身把她逼喷；教训：她输给的不是手指，是规矩
  - **洗脚盆七客十四趾（永久敏感化）**：七人十四只大脚趾轮流插入；脚汗、茧屑、泥灰封存体内；**永久特质：任何人脚趾插入即喷**
  - **封穴发酵与灵虫除秽**：胶带封死发酵约三昼夜；拆封后黏膜吞尽秽物更娇艳；七环除秽她自行报数（数百下不错）；二十只医用白虫入穴啃食，**敏感度 ×6**；浓缩液回刷褶皱；她自拟"妻妾"，主人降为"妻奴"
- **解锁**：名分"娇淫妻奴"、永久特质"遇趾即喷"、蜜穴开发度 2 级

### 第 2 阶：双锁育种（生理锁）
- **目标**：稚宁蜜穴 ↔ 老臭鸡巴双向依赖，同室即自发交合
- **前置**：第 1 阶完成
- **关键模块**：
  - **三层毒**：①**糙舌换菌**——拆封不除秽，老臭糙舌舔净后射精灌菌，体表人菌占优，此后人类手舌被黏膜判为异物 ②**倒钩锁玉**——蜱虫倒钩环戴鸡巴根，射精膨胀卡死阴道口 20-25 分钟，"被锁死"与"终极高潮"焊在一起 ③**垢粮为医**——蜱虫 + 蛞蝓双环趁腺孔最饿时重写 G 点记忆；断粮则奇痒十倍，解法 = 带垢之根戴羊眼圈插入（喂食 + 开锁缺一不可）
  - **五大新规矩（锁死后当场立法）**：①人类禁入（蜜穴只认老臭的鸡巴、羊眼圈和陆渊的指套，任何人含亦舟不得裸手 / 嘴 / 鸡巴直接碰触）②丈夫只剩看、听、抱 ③痒了只许求，私解一次停喂一周 ④每周六上午婚床投喂（校五日皆倒计时）⑤她每晚向丈夫汇报痒的进度，他每周投喂后写观察记录存档。预告三大后续：全套榨乳、肛门夹乳、穿环入珠挂铃

### 第 10 阶：王主任回腌期（轮回管 · 听书 · 妻墨）
- **目标**：俱乐部开光后身上味道"杂"了，用纯夜香把"根"腌回王家。核心调教逻辑——**让她自己参与调教自己：夹紧 = 加料，挣扎 = 循环，身体的本能反应就是泵**
- **前置**：第 9 阶完成
- **关键模块**：
  - **回门酱（腌骨膏）**：排闸口原液滤七遍 + 龙涎香膏 + 吮乳杯陈奶，温养三周，深褐稠可拉丝；抹乳尖 / 逼唇缝 / 后庭缝捂一上午，下午蹲水车刷进肉里，一日三遍；小冯戴羊圈毛手套操作。"馆里用脚腌你，腌的是皮；主任用酱腌你，腌的是骨头。"亦舟每周一三五亲手补腌（酱罐附手写用量表）
  - **九转回轮酥（纯夜香毒香 · 痒淫双绝）**：底矿 = 排闸口最深闸槽底黑亮膏泥（粪心戒同矿最软层）+ 闸壁白色尿酸盐霜（纯夜香的辣，不用外来料）；痒曲 = 老臭一脉脚气真菌只喂夜香粪浆养四十九天，触黏膜如百万细毛从里往外搔；淫髓 = 底浆"过身九转"——喂给前任馆藏淫妻穴温发酵、连蜜带浆排出再加新浆，反复九次，第九转黑亮挂壁吸足淫妻之情，触穴即催淫、穴肉自吮。药性：三息发痒，痒中带酥，酥转淫，灼 / 痒 / 骚三味齐炸；分"头轮"（色浅味淡）与"九转"（黑亮浓稠）两盏做选择局——宁宁避重选轻挑头轮被识破"馋哭"
  - **神仙水（活轮回挂糊液）**：大量龙涎香 + 排闸口浓缩原液（滤七遍再熬，一瓶顶十瓶）+ 趾缝臭液变质版（十几会员趾缝沤水封一个月故意酸败），用时兑九转酥。判词："最干净的少女皮肤、最紧的处子黏膜，一旦沾上，片晌之间自己变成最下贱、最恶臭的一团秽物——奇痒，肿胀，淫欲如海啸"
  - **轮回管（双瓮循环器具）**：小指粗软管，两头蘑菇形玉塞（塞身盘七圈倒生粪毛），前塞蜜穴后塞直肠，**封窍胶**封死（龙涎香蜡 + 医用黏胶，埋羊肠线四时辰自溶）；管中段串半透明**琉璃鼓**（观察窗可见液色走向，兼手摇加压 / 补料 / 换向）。管内四味初入分层（金黄 / 黑褐 / 乳白 / 酱红），循环数轮混成酱紫「**回轮酽**」（黏可拉丝）。原理：蜜穴受刺激 → 本能夹紧 → 液压进直肠 → 肠热绞动 → 回轮酽泵回蜜穴，越夹越快、回波一次比一次狠。驯化结论："夹紧 ≠ 排斥，夹紧 = 加料；想躲的东西，最后都是自己请回来的"。日用：穿管正常办公改作业，板擦敲桌三下 = 当众深蹲十下"加速"；开胶前后同涌酱紫酽液
  - **活轮回（轮回管活人接法 · 惩罚级）**：管另一端**接小冯肛门**——小冯先喂两天黄米 / 肥肉 / 柿饼，当场蹲出一根二十公分又臭又长的成型新鲜夜香棒进管，棒过琉璃鼓时神仙水 + 九转酥挂糊；王主任加压把棒顶入蜜穴"当鸡巴"；宁宁一夹紧棒被挤出或吸深，小冯以**肛门收放控制棒身抽插**（肛收咬棒尾插回 / 肛放顺吸力整根没入）——"屁眼和骚逼隔着一根屎对操"；棒断两截分两次操完，高潮喷出紫黑浆顺管回灌小冯一屁股。王主任语："今天没人替你摇泵，自己摇。"诗题《活轮回 · 屎为媒》
  - **喂骚（毛手套巡坑）**：全校男厕水闸调小、坑底留稠浆；小冯戴羊圈刷毛手套，押宁宁深蹲后入巡四十个坑位，坑底夜香一勺灌一穴，每坑深蹲十下嘬住不许漏，漏了回上坑重灌；诗《喂骚》

  - **听书制度 + 七秒电话（精神教具）**：说书人隔日登门（小冯 / 贺先生）口述实况，夫婿跪听、热茶点心伺候、只许听不许问（问"她疼不疼"即永久停书），每场写《听书录》一首，诗转交受训中的宁宁看——"主任调教她的身子，你这些诗调教她的心"；七秒电话：不定期清晨六点陌生号码，宁宁痒极时打来只够说半句（"老公……"），回拨空号——把"家里这个名字"焊成她的止痒条件反射

### 6.2 终极决胜重器 · 黑金淫狱棒（Hell Rod · 万虫夜香双圈版）

**三重合一构造**：
1. **主杆与马达**：长近半米、表面遍布鱼钩状合金钢刺与微型往复锯齿的暗黑钢体，内置双轴高频马达与不可逆转的物理膨胀齿轮棘轮锁
2. **双舱管**：右舱二百毫升"万香陈酿大权原浆"（四态粪泥拌合她发情甜露熟化）；左舱上百只嗜食黏膜分泌物、极具活性的大号活体臭蠊与甲虫
3. **独创核心 · 秘制夜香淫圈（双环）**：选取多孔深海火山硬骨石与高弹医用硅胶，提前放入男生旧公厕小便沟最底层陈年尿石黄液与陈酿宿便池中浸泡陈化整整三个月，圈体吸透男厕所有最浓重的氨碱与大粪精华；淫圈内沿生有如同蛞蝓勺齿般成千上万细微的"逆向刮肉小密勺"与防滑脱生物钩倒刺

**淫狱棒终极打桩 · 六步流程**（每两周周二"教学大评估日"使用）：
1. **套圈锁外唇**：两枚夜香淫圈一左一右套紧死锁在那两瓣被银坠扯得又大又垂、卷边外翻的红艳花边上，圈体浸透三个月的粪石腥气一秒不停地向外蒸发
2. **黑金直入**：带合金鱼钩倒刺的黑金淫狱棒从被淫圈强行锁张的红门一记猛砸到底
3. **虫便齐进**：双舱管同时开闸，二百毫升万香陈酿与上百只活虫在双马达震动推动下全数狂啸轰入最深处
4. **齿轮落锁**：淫狱棒前端机械花瓣轰然反撑，在最有力的位置"咔啦"扣死——退不能退，闭不能闭
5. **内外夜香共震**：深处二百毫升万香大粪混着活虫疯狂绞食啃噬；外部两枚夜香淫圈带着尿石成瘾刺在翻卷花边上剧震抠挖；最底下两枚十五克纯银坠子随机器疯狂摔打在腿上
6. **全钟扣留**：在粪虫与金属锁环统治中强锁三十分钟。卸下主杆后，那两枚吸透尿石陈屎的夜香淫圈依旧卡在外翻最卷处——她需扣着这副公厕散味环，带着一肚子未漏净的虫子与大便，去走廊上给问好的初二学生带笑解答课文
