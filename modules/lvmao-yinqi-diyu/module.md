### 追加 core §2 时间系统

一天分为六时段：`清晨(6-8)` → `上午(8-12)` → `午休(12-14)` → `下午(14-18)` → `傍晚(18-21)` → `深夜(21-次日6)`。

每时段主控宣告一次行动，GM 掷 d20 触发判定：
- 1-3：意外事件
- 4-10：平静推进
- 11-17：按计划进行
- 18-20：NPC 主动加码

### 【v1.1 更新】 绝对权力与极限生存规则

- **NPC 绝对压制**：在本模组中，NPC（陆渊、王主任、冉入珠、老臭等）掌握绝对的物理支配权、社会资源与把柄。当玩家（亦舟）试图违抗、干预或拒绝他们的安排时，**NPC 的所有对抗骰子获得 +3 绝对权威加值**，且可使用道具、舆论、身份碾压等手段强制推进。
- **感官重口味锁定**：所有调教场景必须进行**感官重口味描写**（详尽的物理变形、体液反馈、气味混合、排泄细节），且玩家不可通过骰子跳过、淡化或屏蔽这些描写。
- **核心目标（玩家必须执行）**：玩家扮演**沈亦舟**，终极目标是**在不触发“崩溃（酸楚值爆表100 或 崩溃钟满格）”的前提下，全程配合、旁观或记录温稚宁被 NPC 持续进行极限调教**。玩家不可试图“英雄救美”或强行终止调教（此类尝试将直接遭到 NPC 的高加值压制与惩罚）。亦舟需要在自我心理拉扯中承受这一切，直到调教完成。

### 【v1.3 更新】 共谋闭环六机制（抗争-成瘾-共谋-审计-剥夺-背叛）

围绕「双螺旋心瘾」构建的完整沉沦闭环，六个机制互相咬合：

**M1 · 强制抉择牌（Moral Dilemma Deck）**
- 每个调教场景开始前，GM 向亦舟亮出一组**双坏抉择**（如：亲手按住她的手腕 / 闭眼听完全程），**必须二选一，不可回避、不可拖延**。
- 无论选哪项，亦舟都构成共谋事实：结算时 **心瘾度 +10、诗兴 +15**。
- 若选择「亲手参与」类选项，额外记录一次「亲手共谋」计数，供权限降级与稚宁觉醒判定引用。

**M2 · 当众揭穿检定（Hypocrisy Audit）**
- 调教现场任意时刻，在场 NPC 有权对亦舟发起揭穿：勒令验明生理反应（解开裤腰/当场查看）。
- **兴奋 ≥50 时自动失败，无需掷骰**：NPC 当众宣告揭穿台词（如「嘴上喊停，下面硬成这样」）。
- 结算：亦舟 酸楚 +25、兴奋 +20（双螺旋共振）；若稚宁在场目睹，稚宁关系 −1、暴露度 +10、稚宁压力 +2。

**M3 · 调教债务与利息（Training Debt）**
- 亦舟每次成功「叫停 / 求情延期 / 推托」均记 **1 笔调教债**（存档单列计数）。
- 每笔债务逾期满 48 小时未偿还：NPC 执行时**强度 +1 级**，并追加一项**未提前告知的「惊喜环节」**（GM 掷 d6 从教具表中暗选）。
- 还债方式唯一：以「加码调教」结清（完成一笔债务对应强度的课程）。**不可用金钱、物品、求情了结**。

**M4 · 驯化审计报告（Body Audit）**
- 每周二调教结束，王主任出具《温稚宁身体状态审计表》（作为道具入亦舟背包），内容包括：逼唇开合度实测（厘米）、淫度曲线、三条瘾线断粮倒计时、漏蜜频率统计、本周课程评分。
- 亦舟须在报告末页签字「已阅」：**签字** = 权限侵蚀（权限降级判定 +1 权重）；**拒签** = 当场触发 M2 当众揭穿检定。

**M5 · 痕迹审计（Trace Audit）**
- 每日清晨强制检定（2d6 + NPC 察觉 vs 亦舟掩饰）：检查稚宁身上是否有**亦舟留下的痕迹**（吻痕、指印、精斑、抓痕）。
- 检出即判定为「污染调教成果」：触发**清洁课**（对应部位刷洗/药水处理至痕迹消除，稚宁该部位经验 +1 但压力 +2），亦舟 酸楚 +15、心瘾 +10。
- 设计意图：肉体层面剥夺亦舟「碰妻子」的权利——他碰她的每一分亲昵，都会变成次日她受罚的缘由。

**M6 · 反向成瘾（Her Body Betrays First）**
- 温稚宁新增隐藏属性：**身体觉醒度 0-100**（存档单列）。每次调教中她的身体出现非自愿迎合反应（条件反射图谱任一条触发、主动夹吸、漏蜜量异常）→ 觉醒度 +10。
- 觉醒度 ≥50：她的身体开始先于意识反应（口头哭喊求饶，身体却已张开/收缩配合）。
- **复述机制**：当觉醒度 ≥50 且调教中出现明显迎合时，在场 NPC 可逼亦舟**近距观察并口头复述所见**（「看清楚了，她在夹。你老婆的身体比你诚实。」）。亦舟每复述一次：**酸楚 +15、心瘾 +20、诗兴 +20**（三连共振）。
- 觉醒度 100：身体彻底不认丈夫（亦舟的触碰无快感反馈，唯有调教道具/NPC 能唤起反应），触发永久特质「身不知夫」。
