# 角色卡模板

> 配合 `rules.md` §1 使用。玩家角色填完整卡；NPC 按重要程度选用完整卡或简卡。

---

## 1. 玩家角色卡

```
## 姓名
- 概念：一句话（例："被赶出师门的药师"）
- 背景：三到五句话
- 目标：想得到什么
- 弱点 / 秘密：会给自己惹麻烦的东西（触发时 +1 经验，见 rules §6.1）

### 属性（1–5）
体魄 N｜敏捷 N｜智识 N｜感知 N｜意志 N｜魅力 N

### 技能（0–3）
格斗 N｜运动 N｜射击 N｜潜行 N｜巧手 N｜学识 N｜医疗 N
工艺 N｜察觉 N｜生存 N｜镇定 N｜交涉 N｜欺瞒 N

### 资源
生命 N/N（体魄×2+4）｜精力 N/N（意志+4）｜压力 N/10
防御值 N（7+敏捷+运动）｜携带格 N（6+体魄）｜决心 N（意志×2+4，社交冲突用）

### 特质
- 特质名：效果

### 装备
- 手中 / 腰间：
- 背包：
- 资金：

### 状态
- （无）

### 经验
- 当前：N　　累计：N
```

## 2. NPC 完整卡（重要 NPC）

```
## 姓名
- 身份：
- 外貌：一两个让人记住的细节
- 说话方式：口头禅、语气
- 动机：想要什么
- 秘密：不愿让人知道的事（GM 专用）
- 对主角的态度：关系值 N（见 rules §8）
- 能提供：消息 / 道具 / 庇护 / 门路
- 会在什么情况下背叛或翻脸：

### 数值
属性：体魄 N 敏捷 N 智识 N 感知 N 意志 N 魅力 N
关键技能：技能 N，技能 N
生命 N｜防御值 N｜决心 N｜武器等级 N｜护甲 N
```

## 3. NPC 简卡（路人、敌人）

```
名称｜生命 N｜防御值 N｜攻击 +N（武器等级 N）｜护甲 N｜特点：一句话
```

**快速分级**

| 等级 | 攻击加值 | 生命 | 防御值 | 例 |
|------|----------|------|--------|-----|
| 杂兵 | +2 | 4 | 7 | 混混、野狗 |
| 普通 | +3 | 6 | 8 | 守卫、打手 |
| 老手 | +5 | 8 | 10 | 队长、老猎人 |
| 精英 | +6 | 10 | 11 | 高手、猛兽 |
| 首领 | +7 | 14 | 12 | 帮主、怪物（每轮可行动两次） |

## 4. 示例：阿澄（玩家角色）

- 概念：替码头工人讨公道的前巡捕
- 背景：因为不肯收钱被赶出巡捕房，现在在老街租房，靠跑腿和打零工过活。
- 目标：查清码头走私案背后是谁。
- 弱点 / 秘密：见不得人被欺负，经常不管不顾地出头。

**属性**：体魄 2｜敏捷 3｜智识 2｜感知 3｜意志 2｜魅力 2（1×6 起，分配 8 点）
**技能**：格斗 1｜运动 1｜潜行 2｜察觉 2（共 6 点，其余 0）
**资源**：生命 8/8｜精力 6/6｜压力 0/10｜防御值 11｜携带格 8｜决心 8
**特质**：侦探——调查场景时额外获得一条线索
**装备**：武器——短棍（腰间）；随身物——旧巡捕证；杂物——火柴、笔记本、绳子；资金 10
**状态**：无
**经验**：0
