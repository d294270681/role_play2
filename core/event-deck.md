# 事件牌 · 通用框架

> 配合 `rules.md` §4.2 使用：时段结束时 1d6 ≤ 地点危险度 → 抽一张事件。
> 抽法：掷两颗 d6，第一颗为十位、第二颗为个位（d66，11–66 共 36 格）。
> 下表是题材中立的示例；换题材时替换名称和细节，保留结构即可。

---

## 1. 事件模板

```
### [d66] 事件名
- 类型：遭遇 / 机遇 / 线索 / 环境 / 社交 / 威胁
- 触发条件：（可选）某地点、某时段、某进度钟 ≥ N、某关系值……不满足则顺延到下一格
- 场面：一两句话描述玩家看到/听到的东西
- 选项：
  A. 做法 → 判定（属性 + 技能，难度）→ 成功 / 代价成功 / 失败的后果
  B. 做法 → ……
  C. 无视 / 离开 → 后果（通常是错过机会或威胁钟 +1）
- 后续：写入存档的内容（新线索、新 NPC、进度钟、状态）
```

**抽到重复事件**：同一冒险中已触发过的事件，改用相邻格（+1，66 之后回到 11）。
**抽到不适用的事件**（触发条件不满足）：同样顺延到相邻格。

---

## 2. 事件分布

| 十位 | 类型 | 基调 |
|------|------|------|
| 1 | 遭遇 | 有人或有东西挡路 |
| 2 | 机遇 | 可以捡到好处，但通常有代价 |
| 3 | 环境 | 天气、地形、意外故障 |
| 4 | 社交 | NPC 主动找上门 |
| 5 | 线索 | 与当前主线相关的信息浮出水面 |
| 6 | 威胁 | 推进一个威胁进度钟，或让它露出苗头 |

---

## 3. 示例事件（12 张）

### 11 拦路者
- 类型：遭遇
- 场面：两三个人堵在去路上，说要"过路费"。
- 选项：
  A. 付钱（资金 −3）→ 放行，无判定。
  B. 交涉 / 欺瞒 vs 对方头目镇定 → 胜：免费通过；平：付一半；负：进入冲突。
  C. 动手 → 冲突（对手：生命 6，防御值 8，武器等级 1）。
- 后续：若击败对方，获得一条关于当地势力的传闻。

### 14 受伤的陌生人
- 类型：遭遇
- 场面：路边有人倒在血泊里，还在呼吸。
- 选项：
  A. 救治 → 医疗（普通 9）→ 成功：新 NPC，关系 +2；代价成功：消耗 1 件医疗用品；失败：对方死去，压力 +1。
  B. 搜身 → 察觉（简单 7）→ 找到一件杂物或 1d6 资金；若对方醒着，关系 −3。
  C. 离开 → 无事。
- 后续：此人可能是某势力的逃兵或信使（由 GM 决定，写进角色卡的秘密栏）。

### 23 无人看管的货物
- 类型：机遇
- 场面：一车货停在角落，看守不见了。
- 选项：
  A. 顺手拿 → 巧手 / 潜行（普通 9）→ 成功：得到 1 件普通道具；代价成功：得手但被人看见（该势力关系 −1）；失败：被抓现行，进入社交冲突。
  B. 等看守回来，帮忙看着 → 占用本时段，看守关系 +1，得到 2 资金。
- 后续：无。

### 26 黑市摊贩
- 类型：机遇
- 场面：一个不起眼的摊位在卖稀有货。
- 选项：
  A. 购买 → 提供 1 件稀有道具，价格为标价 ×1.5；交涉（困难 11）成功可降到原价。
  B. 打听 → 交涉（普通 9）→ 成功：得到一条线索（对应主线进度钟 +1）。
- 后续：记录摊贩为 NPC，之后在同地区可再次找到。

### 31 天气骤变
- 类型：环境
- 场面：暴雨 / 风雪 / 沙暴 / 浓雾（按题材）。
- 效果：本时段和下一时段，察觉与射击判定 −1；户外移动耗时 +1 时段。
- 选项：
  A. 硬闯 → 生存（普通 9）→ 失败：获得"疲惫"。
  B. 找地方躲避 → 本时段消耗，下一时段危险度 −1。

### 34 断路
- 类型：环境
- 场面：前方道路塌了、桥断了、门锁死了。
- 选项：
  A. 绕路 → 移动耗时 +1 时段，额外一次事件判定。
  B. 强行通过 → 运动（困难 11）→ 失败：受 2 伤。
  C. 修复 / 撬开 → 工艺或巧手（普通 9）→ 成功后此路在存档中标记为"已打通"。

### 42 旧识
- 类型：社交
- 触发条件：主角背景里有旧识，或存档里有关系 ≠ 0 的 NPC。
- 场面：一个认识主角的人叫住了他/她。
- 选项：
  A. 叙旧（占用本时段）→ 关系 +1，压力 −1；对方顺带提起一件麻烦事（新支线）。
  B. 假装不认识 → 欺瞒 vs 察觉 → 失败：关系 −1。
- 后续：若关系 ≤ −1，对方不是来叙旧的，而是来讨债的。

### 45 有人跟踪
- 类型：社交
- 场面：同一个人第三次出现在视野边缘。
- 选项：
  A. 甩掉 → 追逐冲突（双方各 6 格钟）。
  B. 反跟踪 → 潜行 vs 察觉 → 胜：发现对方是谁派来的。
  C. 当面对质 → 进入社交冲突。
- 后续：派出跟踪者的势力，其威胁钟 +1（若玩家被甩掉/失败）。

### 52 遗落的信件
- 类型：线索
- 场面：地上有一封被踩脏的信 / 一段录音 / 一页笔记。
- 选项：
  A. 解读 → 学识（普通 9）→ 成功：主线进度钟 +1；大成功：+2 并得知一个 NPC 的秘密。
- 后续：信的主人可能会回来找它。

### 55 目击者
- 类型：线索
- 场面：一个紧张的人说"我看见了那天晚上的事"。
- 选项：
  A. 问话 → 交涉（普通 9）或给钱（资金 −3，自动成功）→ 主线进度钟 +1。
  B. 识破 → 察觉 vs 对方欺瞒 → 胜：发现证词里有一处是编的（这本身也是线索）。
- 后续：若对方被灭口的威胁钟存在，推进 1 格。

### 61 风声
- 类型：威胁
- 场面：街头巷尾在议论主角最近做的事。
- 效果：当前最显眼的威胁钟 +1；若主角带有"通缉 / 暴露"状态，改为 +2。

### 64 对手先到一步
- 类型：威胁
- 触发条件：存在"竞争"类进度钟。
- 场面：主角赶到时，发现有人已经来过——翻乱的抽屉、被收买的线人。
- 效果：竞争钟 +1。
- 选项：
  A. 追踪痕迹 → 生存 / 察觉（困难 11）→ 成功：得知对手下一步去向，竞争钟 −1。

## 4. 自定义事件清单

按上面的模板把剩下的格子补全即可。建议每个题材至少写满 18 格（每类 3 张），其余格子可以统一写成"平静：本时段无事发生，压力 −1"。
